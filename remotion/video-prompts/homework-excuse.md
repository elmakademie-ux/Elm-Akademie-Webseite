# Die Hausaufgaben-Ausrede – Clips für Bild-zu-Video

Pro Szene ein Clip aus dem Szenenbild (`public/assets/scene-0X.png`) erzeugen. Wenn das Werkzeug eine **Audio-/Lip-Sync-Funktion** hat, die Sprachdatei der Zeile hochladen. Der Clip sollte mindestens so lang sein wie angegeben.

**Stil-Zusatz für jeden Prompt:** 2D cartoon, flat colours, thick black outlines. Keep both characters EXACTLY like the reference image (face, hair, glasses, clothes, colours), keep the same classroom, no style change, no new characters, no text, no subtitles. Vertical 9:16, 24-30 fps, natural lip-sync.

## Clips einsetzen
In `src/clips.json` eintragen (Länge in Frames bei 30 fps = Sekunden × 30):
```json
{ "teacher/pointing": { "file": "assets/clips/teacher-pointing.mp4", "frames": 90 } }
```
Danach wie gewohnt rendern; Untertitel, Ton, Schnitte und Logo bleiben unverändert.
